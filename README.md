# Perl CLI Calculator

A command-line arithmetic calculator developed in Perl. It processes basic mathematical operations while providing robust protection against invalid user input.

## Key Features
* Basic Operations: Supports addition, subtraction, multiplication, and division.
*Flexible Commands: Case-insensitive input parsing. Recognizes symbols, full names, or abbreviations.
*Robust Validation: Safely handles bad user inputs without crashing, prompting the user for correct data. Includes division-by-zero protection.
*Session History: Tracks all successful calculations and invalid attempts, displaying the complete history upon exiting.
